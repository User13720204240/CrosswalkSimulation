# 无信号灯人行横道车辆-行人交互仿真

这是一个使用 MATLAB 实现的无信号灯人行横道仿真项目，模拟车辆与行人在人行横道处的交互行为。项目包括：
- **数值仿真**（`simu.m`）：基于 FVD 跟车模型和概率决策，计算车辆延误和行人等待时间。
- **可视化界面**（`simu_1.m`）：提供交互式 GUI，实时展示车辆和行人动态。


## 功能
- 模拟多车道车辆流（支持自定义车流量，如 300-1000 veh/h/lane）。
- 模拟行人过街行为（支持自定义行人流量，如 0-500 ped/h）。
- 计算车辆平均延误和行人平均等待时间。
- 提供直观的 GUI 可视化，显示车辆和行人在人行横道处的交互。
